# رقم المشتري — الساحة العراقية

تطبيق أندرويد لأسماء وأرقام المشترين، مشترك بين كل الأجهزة (نفس القائمة ونفس التثبيتات).

- شريط علوي للأسماء المثبتة بمدة (ساعة، يوم، أسبوع، مخصص…) — التثبيت يطلع على كل الأجهزة
- إضافة اسم (أو اختياره من جهات الاتصال)، تعديل، حذف، اتصال، واتساب، نسخ
- زر تحديث: يفحص آخر نسخة بـ Releases وينزلها ويثبتها من داخل التطبيق
- السيرفر: مجلد `server/` بالـ ZIP (PHP + MySQL) يرفع على الاستضافة

تطوير: علي حميد
